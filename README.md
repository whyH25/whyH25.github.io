## Repository Structure

빌드 도구 없는 정적 사이트입니다. `index.html`을 브라우저로 열면 그대로 확인할 수 있습니다.

```text
├── index.html   # 포트폴리오 페이지 구조
├── style.css    # 페이지 스타일 및 반응형 디자인
├── script.js    # 인터랙션 및 동작 구현
└── img/         # 히어로 배경 및 프로젝트 스크린샷
```
